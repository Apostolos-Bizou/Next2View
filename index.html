◈ Dashboard — Η Κεντρική Σελίδα
Το Dashboard είναι η πρώτη σελίδα που βλέπεις μόλις μπεις στο Next2View. Από εδώ έχεις άμεση εικόνα για όλες τις εταιρείες και τα projects χωρίς να χρειαστεί να ψάξεις πουθενά.
📊 KPI Strip — Τα 6 βασικά νούμερα
%
Overall
Μέσος όρος % ολοκλήρωσης όλων των active projects του group.
$
Finance
Μέσο % ολοκλήρωσης όλων των Finance projects.
⚖
Legal
Μέσο % ολοκλήρωσης όλων των Legal projects.
⌨
Developing
Μέσο % ολοκλήρωσης όλων των Dev projects.
◈
Marketing
Μέσο % ολοκλήρωσης όλων των Marketing projects.
⚠
At Risk
Αριθμός projects που χρειάζονται άμεση προσοχή (blocked, stale, deadline σε κίνδυνο).
💡 Tip: Αν το "At Risk" δείχνει >0, κοίτα το κόκκινο banner στην κορυφή — σου λέει ακριβώς ποια projects έχουν πρόβλημα.
🏢 Panel Εταιρειών
Δείχνει κάθε εταιρεία με τον αριθμό projects και το % ολοκλήρωσης. Κάνε κλικ σε μία εταιρεία για να δεις μόνο τα projects της.
📅 Upcoming Deadlines
Τα επόμενα 5 deadlines ταξινομημένα χρονολογικά με χρωματική ένδειξη:
🔴 <7 ημέρες — Urgent 🟡 7-14 ημέρες — Προσοχή 🟢 >14 ημέρες — OK
📅 Timeline Gantt
Στο κάτω μέρος του Dashboard βλέπεις όλα τα projects σε εβδομαδιαίο Gantt chart. Η μπλε κάθετη γραμμή δείχνει την τρέχουσα εβδομάδα. Μπορείς να φιλτράρεις ανά κατηγορία με το dropdown πάνω δεξιά.
💡 Tip: Κάνε κλικ στον τίτλο ενός project στο Gantt για να πας απευθείας στη σελίδα του.
🏢 Διαχείριση Εταιρειών
Οι εταιρείες είναι η βάση της οργάνωσης. Κάθε project ανήκει σε μία εταιρεία.
➕ Πώς προσθέτω νέα εταιρεία
1
Πάτα "+ Company" στο κάτω μέρος του sidebar αριστερά.
2
Συμπλήρωσε το όνομα εταιρείας (π.χ. "Polaris Financial Services").
3
Βάλε ένα Short Code 2-3 γραμμάτων (π.χ. "PF") — εμφανίζεται ως avatar.
4
Επίλεξε χρώμα για να ξεχωρίζει οπτικά.
5
Πάτα "Save Company". Εμφανίζεται αμέσως στο Dashboard και στο sidebar.
🗑 Πώς διαγράφω εταιρεία
Πήγαινε στο Manage (sidebar) → Companies → πάτα ✕ δίπλα στην εταιρεία. Προσοχή: τα projects της εταιρείας δεν διαγράφονται αυτόματα.
💡 Tip: Το χρώμα κάθε εταιρείας εμφανίζεται συνεπώς παντού — dashboard, progress bars, labels. Επίλεξε χρώματα που ξεχωρίζουν μεταξύ τους.
⬡ Διαχείριση Projects
Κάθε project αντιπροσωπεύει μία εργασία ή ανάπτυξη που παρακολουθείς. Ένα project έχει κατηγορία, budget, deadline, modules και tasks.
➕ Πώς δημιουργώ νέο project
1
Πάτα "+ New Project" στο sidebar ή στην κορυφή δεξιά.
2
Συμπλήρωσε τον τίτλο (π.χ. "IMO CII Compliance 2026").
3
Επίλεξε Εταιρεία και Κατηγορία (Finance / Legal / Developing / Marketing).
4
Βάλε Budget (€) και Deadline (ημερομηνία).
5
Γράψε σύντομη περιγραφή σύμβασης — τι αφορά το project.
6
Πρόσθεσε Specifications — checklist με τα deliverables (π.χ. "Υποβολή εγγράφων Flag State").
7
Δημιούργησε Modules — οι φάσεις του project (π.χ. "Assessment Phase", "Submission", "Training").
8
Μέσα σε κάθε Module πρόσθεσε Tasks με assignee, deadline και % ολοκλήρωσης.
9
Πάτα "Save Project". Εμφανίζεται αμέσως στο Dashboard και στο Timeline.
✏️ Πώς επεξεργάζομαι project
Από το Project Detail (κλικ σε project) → πάτα το ✎ εικονίδιο πάνω δεξιά στο contract header. Ανοίγει το ίδιο form με όλα τα στοιχεία προγεμισμένα.
🔍 Πώς φιλτράρω projects
Στο "All Projects" view υπάρχουν 2 dropdowns πάνω δεξιά: ένα για κατηγορία και ένα για εταιρεία. Μπορείς επίσης να κάνεις κλικ σε κατηγορία ή εταιρεία από το sidebar.
📊 Status ενός project
🟢 On Track — Στο σωστό δρόμο 🟡 Delayed — Καθυστέρηση 🔴 At Risk — Blocked ή deadline κοντά με χαμηλό % 🔴 Stale — Δεν ενημερώθηκε >5 ημέρες
💡 Tip: Το status υπολογίζεται αυτόματα. Δεν χρειάζεται να το ορίσεις χειροκίνητα.
✅ Tasks & Modules
Τα Tasks είναι οι μικρότερες μονάδες εργασίας. Οργανώνονται σε Modules (φάσεις). Το % κάθε Module = μέσος όρος tasks. Το % κάθε Project = μέσος όρος modules.
📐 Δομή: Project → Module → Task
⬡ Project — π.χ. "ATLANTIS ERP" (88% = μέσος όρος modules)
▣ Module — π.χ. "Core Modules" (100% = μέσος όρος tasks)
· Task — π.χ. "Dashboard" ✓ 100%
· Task — π.χ. "Payroll calculator" 40%
📝 Πώς ενημερώνω ένα task
1
Πήγαινε στο Project Detail (κλικ στο project).
2
Κάνε κλικ στον τίτλο ενός Module για να το ανοίξεις/κλείσεις.
3
Βλέπεις κάθε task με: checkmark, όνομα, assignee, progress bar και %.
4
Για να αλλάξεις %, πήγαινε Edit Project (✎) → αλλάζεις το % του task → Save.
💬 Πώς προσθέτω σχόλιο σε task
1
Στο Project Detail, άνοιξε ένα Module.
2
Πάτα το 💬 εικονίδιο δεξιά σε κάθε task.
3
Γράψε το σχόλιο και πάτα "Αποθήκευση".
4
Το σχόλιο εμφανίζεται ως preview κάτω από το task name και το AI το λαμβάνει υπόψη στις αναφορές.
🚫 Πώς σημαδεύω ένα task ως Blocked
Στο Edit Project → βάλε στο task note τη λέξη "BLOCK" και την αιτία (π.χ. "BLOCK — αναμένει έγγραφα από Flag State"). Το task εμφανίζεται με κόκκινο εικονίδιο και το project περνά σε status "At Risk".
💡 Tip: Ένα task με 100% θεωρείται αυτόματα ✓ Done. Δεν χρειάζεται να κάνεις τίποτα άλλο.
📄 Διαχείριση Συμβάσεων
Κάθε project μπορεί να έχει ανεβασμένη την υπογεγραμμένη του σύμβαση. Το AI εξάγει αυτόματα τα βασικά στοιχεία και τα εμφανίζει ως δομημένη καρτέλα.
⬆️ Πώς ανεβάζω σύμβαση
1
Πήγαινε στο Project Detail του project που θέλεις.
2
Βρες το panel "Υπογεγραμμένη Σύμβαση" στη δεξιά στήλη.
3
Πάτα "Ανέβασε τώρα" ή κάνε drag & drop το αρχείο.
4
Υποστηριζόμενες μορφές: PDF, JPG, PNG έως 10MB.
5
Μόλις ανέβει, το AI ξεκινά αυτόματα την εξαγωγή στοιχείων.

Παροχή υπηρεσιών ανάπτυξης ολοκληρωμένου ERP συστήματος διαχείρισης πληρωμάτων και στόλου για θαλάσσιες μεταφορές, περιλαμβανομένης εκπαίδευσης χρηστών και υποστήριξης 12 μηνών.

4.Παράδοση πλήρους τεκμηρίωσης και source code σε ασφαλές αποθετήριο

Επίσης δίνει πρόβλεψη ολοκλήρωσης με βάση τον τρέχοντα ρυθμό και προτεινόμενες ενέργειες.
🔔 Σύστημα Notifications
Το Next2View σε ειδοποιεί αυτόματα για κάθε κρίσιμο event — χωρίς να χρειάζεται να κοιτάς συνέχεια το dashboard. Κάθε 5 λεπτά ελέγχονται όλα τα active projects.
🔔 Το Bell Icon
Το 🔔 εμφανίζεται στο κάτω μέρος του sidebar. Όταν υπάρχουν νέα notifications, εμφανίζεται κόκκινο badge με τον αριθμό των αδιάβαστων. Κάνε κλικ για να ανοίξεις το panel.
💡 Το badge παλμοδεί για να τραβήξει την προσοχή σου. Μόλις ανοίξεις το panel, τα notifications σημαδεύονται ως διαβασμένα.
⚡ 5 Αυτόματα Triggers
🚨
Deadline Risk
ΚΡΙΣΙΜΟ
Πότε: Λιγότερες από 7 ημέρες στο deadline και πρόοδος κάτω από 80%.
Τι σημαίνει: Το project κινδυνεύει να μην παραδοθεί εγκαίρως. Απαιτείται άμεση δράση.
😴
Stale Project
ΠΡΟΣΟΧΗ
Πότε: Το project δεν έχει ενημερωθεί για περισσότερο από 5 ημέρες.
Τι σημαίνει: Το αρμόδιο τμήμα δεν αναφέρει πρόοδο. Κάποιος δεν κάνει τη δουλειά του.
⏱
Time vs Progress Gap
ΠΡΟΣΟΧΗ
Πότε: Έχει περάσει πάνω από το 70% του συνολικού χρόνου αλλά η πρόοδος είναι κάτω από 50%.
Τι σημαίνει: Ο ρυθμός ανάπτυξης δεν φτάνει για να τελειώσει εγκαίρως. Χρειάζεται επιτάχυνση.
🚫
Blocked Task
ΚΡΙΣΙΜΟ
Πότε: Οποιοδήποτε task έχει σημανθεί ως "BLOCK" με αιτία.
Τι σημαίνει: Κάτι εξωτερικό μπλοκάρει την εξέλιξη. Χρειάζεται παρέμβαση από τον CEO.
💰
Under-billed
ΧΡΗΜΑΤΙΚΟ
Πότε: Η πρόοδος του project ξεπερνά κατά 30%+ αυτό που έχεις χρεώσει.
Τι σημαίνει: Δουλεύεις αλλά δεν χρεώνεις. Κίνδυνος απώλειας εσόδων — έλεγξε τις πληρωμές.
📩 Toast Notifications
Κάθε νέο notification εμφανίζεται ως toast κάτω δεξιά της οθόνης για 5 δευτερόλεπτα. Κάνε κλικ πάνω του για να πας απευθείας στο project που αφορά.
🌐 Browser Push Notifications
Μόλις ανοίξεις το Next2View, ο browser σου ζητά permission για notifications. Αν αποδεχτείς:
1
Λαμβάνεις notifications ακόμα και αν το tab είναι σε background.
2
Στο κινητό (Android Chrome / iOS Safari 16.4+) εμφανίζονται ως push notifications στο σύστημα.
3
Μετά το deploy στο Azure, λειτουργούν πλήρως ακόμα και με κλειστό browser.
💡 Αν δεν είδες το αίτημα permission: Πήγαινε στις ρυθμίσεις του browser → Site Settings → Notifications → Επέτρεψε για αυτή τη σελίδα.

Βασικοί όροι που χρησιμοποιούνται στο Next2View.
Project
Μία εργασία ή ανάπτυξη που παρακολουθείς (π.χ. "IMO CII Compliance", "HireBase MVP"). Κάθε project ανήκει σε εταιρεία και κατηγορία.
Module
Φάση ή ενότητα ενός project (π.χ. "Assessment Phase", "Frontend UI"). Περιέχει tasks.
Task
Η μικρότερη μονάδα εργασίας. Έχει assignee, deadline και % ολοκλήρωσης (0-100%).
% Completion
Task % → Module % (μέσος όρος tasks) → Project % (μέσος όρος modules). Υπολογίζεται αυτόματα.
Status
Αυτόματη κατάσταση project: On Track / Delayed / At Risk / Stale. Βασίζεται στο %, deadline και blockers.
Stale
Project που δεν έχει ενημερωθεί για περισσότερο από 5 ημέρες. Εμφανίζεται με κόκκινο warning.
Blocked
Task που δεν μπορεί να προχωρήσει λόγω εξωτερικού παράγοντα. Σημαδεύεται με "BLOCK" στο note.
At Risk
Project με blocked task, ή deadline <7 ημέρες με χαμηλό %, ή stale >5 ημέρες.
KPI
Key Performance Indicator — τα βασικά νούμερα που βλέπεις στα cards του Dashboard.
Gantt Timeline
Εβδομαδιαίο γράφημα που δείχνει πότε τρέχει κάθε task. Η μπλε γραμμή = σήμερα.
Contract Summary
Αυτόματη εξαγωγή βασικών στοιχείων από ανεβασμένη σύμβαση (PDF/εικόνα) μέσω AI.
CEO Notes
Private σημειώσεις του CEO σε κάθε project. Δεν τις βλέπουν άλλοι χρήστες.
SAS Token
Προσωρινό, ασφαλές link για πρόσβαση σε αρχεία (π.χ. συμβάσεις). Ισχύει 1 ώρα.
Notification
Αυτόματη ειδοποίηση για κρίσιμο event (deadline, blocked task, stale project κλπ). Εμφανίζεται ως toast και στο bell panel.
Toast
Προσωρινή ειδοποίηση που εμφανίζεται κάτω δεξιά για 5 δευτερόλεπτα. Κλικ πάνω της για να πας στο project.
Under-billed
Project που η πρόοδός του ξεπερνά κατά 30%+ αυτό που έχει χρεωθεί. Κίνδυνος απώλειας εσόδων.
